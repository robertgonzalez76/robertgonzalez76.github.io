# Alex Rivera — IT Graduate Portfolio

A static personal portfolio website for a fictional newly graduated Information Technology professional.

Built with plain HTML5 and CSS3 — no JavaScript frameworks, no build tools.

## Live Site

Once deployed: `https://<your-username>.github.io`

## File Structure

```
site/
├── index.html          ← Main portfolio page
├── css/
│   └── style.css       ← All styles
└── images/
    ├── profile.svg     ← Profile photo
    ├── hero-bg.svg     ← Header background
    ├── github-icon.svg ← GitHub contact icon
    └── linkedin-icon.svg ← LinkedIn contact icon
```
